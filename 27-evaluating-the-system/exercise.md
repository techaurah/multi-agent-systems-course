# Exercise: Evaluating the system: per-agent metrics and fault attribution

Inject two faults at once: the budget-dropping extractor and the discount-adding drafter. Count the new failures and run the attribution rule. What does it report, and what can it not see?

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
