# Exercise: Loops: the conversation that never finishes

Tighten the supervisor: escalate when the same payload arrives for the second time instead of the third. How many messages does the loop now consume, and what is the risk of the tighter threshold in a system where a legitimate retry can repeat a payload once?

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
