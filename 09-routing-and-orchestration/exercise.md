# Exercise: Routing and orchestration: send each order the cheapest safe way

Make the router more cautious: route to review every urgent order as well. Count how many orders now get reviewed, what the successes are, and what the mean token cost becomes. Is the caution worth it on this fixture set?

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
