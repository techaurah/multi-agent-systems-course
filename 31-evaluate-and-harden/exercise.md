# Exercise: Evaluate and harden: the verdict, the failed gate, and the fix

Tighten one gate on paper: tokens per success at most 340 instead of 400. Recompute the hardened system's verdict against it from this lesson's printed numbers. Does the system still ship, and what would you change, the gate or the system, and on what evidence?

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
