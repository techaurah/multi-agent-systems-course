# Showcase

Built something with the course's patterns: a routed review system, a cost ledger for your own agents, a failure taxonomy profile of your workload? Open a pull request adding a short entry here: what you built, which lessons it used, and the numbers you measured (successes, escapes, tokens per success) rather than adjectives.

Entries should follow the course's own standard: claims with the code or fixtures that produced them, honest negatives included. A showcase entry that reports a case where multi-agent lost to a single agent is as welcome as one where it won; Lesson 05 exists because that result is information, not embarrassment.
