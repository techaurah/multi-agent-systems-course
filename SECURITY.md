# Security Policy

## Scope

This is a teaching repository. All runnable code uses the Python standard library, makes no network calls, requires no API keys, and processes only the bundled fictional fixture data (Fernhill Garden Centres is an invented company; the leads are synthetic). There is no production system, user data, or credential handling in this repo.

## Reporting a vulnerability

If you find something that behaves contrary to that scope (for example, code that reads files outside the repo, executes unexpected input, or a fixture that appears to contain a real person's data), please report it privately through the contact channels on the [TechAura website](https://techaurah.com) rather than opening a public issue. Include the file, the lesson, and what you observed.

## Supported versions

Only the latest release is maintained. Fixes land on `main` and are noted in the CHANGELOG.
