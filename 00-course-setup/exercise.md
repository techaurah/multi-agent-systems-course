# Exercise: Course setup: what you need, and how this course works

Open `fixtures/orders.json` and `fixtures/leads.json`. By hand, work out which orders have an expected score of 90 or more, and which leads state no budget at all. Then check your answers against the `expected` blocks and the `truth` blocks. Write down why a course about coordination would bother fixing the expected answers in advance.

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
