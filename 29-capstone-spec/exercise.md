# Exercise: Capstone spec: the system and its gates, fixed in advance

Stress the gates on paper before Lesson 30 runs. If the success gate were 0.80 instead of 0.90, which systems from Lesson 24's table would pass it, and what would the weaker gate fail to force? If the tokens-per-success gate were 350 instead of 400, which of Lesson 24's systems would fail it?

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
