# Exercise: Choosing a topology: the decision table, computed

Change the decision rule: cheapest cost per success first, with success only as a tiebreak, and restrict attention to systems that score at least one success in a family. Which family changes its pick, and what does the change reveal about the original rule?

Work it with the lesson's code open beside you. Every number in the worked solution comes from running a variant of that code, and you should be able to reproduce each one.
